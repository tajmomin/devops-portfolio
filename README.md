# 🛠️ DevOps Portfolio — SE202

A collection of shell scripts and coursework from my DevOps studies, covering Linux system administration, file management, and backup automation.

---

## 📁 Files

| File | Description |
|------|-------------|
| `systeminfo.sh` | Displays current user, working directory, date, disk usage, and memory stats |
| `backup.sh` | Creates a timestamped `.tar.gz` archive of the home directory |
| `file_organizer.sh` | Scans the current directory and lists all `.txt` files |
| `aboutme.html` | A simple HTML page introducing my background and skills |

---

## 🚀 Getting Started

**Requirements:** Linux, WSL, or any Bash-compatible shell

```bash
# Clone the repo
git clone https://github.com/your-username/devops-portfolio.git
cd devops-portfolio

# Make scripts executable
chmod +x *.sh
```

---

## 💻 Usage

```bash
# View system info
./systeminfo.sh

# Run a backup (creates backup_YYYYMMDD.tar.gz)
./backup.sh

# List .txt files in current directory
./file_organizer.sh
```
